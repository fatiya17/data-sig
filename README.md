# Geographic Information System Data

This repository contains CSV data used for the Geographic Information System (GIS) practical assignment.

The data contains geographic information about provinces, regencies, and cities in Indonesia, including latitude and longitude coordinates.

## Repository Structure

```text
data-sig/
├── kabupaten-kota/

│   ├── DI Yogyakarta.csv
│   ├── DKI Jakarta.csv
│   ├── Jawa Barat.csv
│   ├── Jawa Tengah.csv
│   ├── Jawa Timur.csv
│   └── README.md
│
└── provinsi/
    ├── Indonesia Timur.csv
    ├── Jawa dan Bali.csv

    └── README.md
```

## Data

### Province Data

The `provinsi` folder contains province data from Indonesia. The data is divided into five regions:

- Sumatera
- Jawa dan Bali
- Kalimantan
- Sulawesi
- Indonesia Timur

### Regency and City Data

The `kabupaten-kota` folder contains regency and city data from Java Island. The data is divided into six regions:

- Banten
- DKI Jakarta
- Jawa Barat
- Jawa Tengah
- DI Yogyakarta
- Jawa Timur

## Data Process

The data was imported into Google My Maps and used as map layers. The GPS coordinates were checked, and incorrect locations were corrected before the data was exported back to CSV.
